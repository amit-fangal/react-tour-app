# React Tour App

A simple and interactive React application that displays different tour destination cards with images, prices, and descriptions.

Users can remove tours they are not interested in, and when all tours are removed, a refresh button allows the original tour list to be restored.

## Live Demo

🔗 Live Website: https://react-tour-app-sigma.vercel.app/

## Features

* Display multiple tour destination cards
* Show city image, price, and description
* "Read More / Show Less" functionality
* Remove tours dynamically using state management
* Refresh all tours after removing every card
* Responsive and clean UI

## Installation

Clone the repository:

```bash
git clone https://github.com/amit-fangal/react-tour-app.git
```

Move into the project folder:

```bash
cd react-tour-app
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

## Deployment

This project is deployed on Vercel.
